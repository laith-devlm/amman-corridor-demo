# من رغدان لصويلح · ع الأوتوستراد (نموذج تجريبي)
لعبة قيادة متصفح أصلية (Three.js) بمسار عمّاني مُبسّط وغير دقيق جغرافياً: رغدان ← وسط البلد ← الداخلية ← المدينة ← الجامعة الأردنية ← صويلح.
التحكم: الأسهم/WASD، أو أزرار اللمس.

Original Three.js browser driving prototype (stylized corridor, NOT GPS-accurate). Inspired by the highway-driving genre only; no third-party assets. Controls: arrows/WASD, or on-screen touch buttons.
